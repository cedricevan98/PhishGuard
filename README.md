**Phishing Detection & Analysis Platform** — Analyze URLs, emails, and domains for phishing indicators.  
Powered by **[NexusCore](https://github.com/cedricevan98/NexusCore)** — custom Python WSGI framework (no Django, no Flask).

---

## Features

- **URL Phishing Analyzer** — 18 heuristic rules
- **Domain Typosquatting Detector** — Levenshtein edit distance
- **Email Analyzer** — Parse raw email
- **Bulk URL Analysis** — Up to 10 URLs
- **Risk Scoring** — Weighted scoring
- **Analysis History** — Searchable result store
